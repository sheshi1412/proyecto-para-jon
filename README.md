# Portafolio — Sherdi Sebastian Espinosa Bazet

Landing page de CV (one-page, responsiva) y página de referencia visual del sistema de diseño personal. Diseñado a partir de los tokens de `DESIGN.md`: paleta carmesí y negro, tipografías Olana, Moranga, Helvetica y Times New Roman, espaciado en múltiplos de 8px y base plana con elevaciones funcionales.

## Páginas publicadas

- **Landing CV:** https://sheshi1412.github.io/proyecto-para-jon/
- **Sistema de diseño:** https://sheshi1412.github.io/proyecto-para-jon/design.html

> Nota: para que estos enlaces funcionen, activa GitHub Pages en el repositorio (Settings → Pages → Deploy from a branch → rama `master`).
